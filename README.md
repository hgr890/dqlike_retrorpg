# ドラゴンクエスト風のレトロ2Dタイルベース RPG。  
## 実行方法

### exe を実行

./target/release/retrorpg.exe

### ビルドについて

```bash
# プロジェクトのディレクトリへ移動
cd /retrorpg

# リリースビルド
cargo build --release

# 生成された exe を実行
./target/release/retrorpg.exe
```

## 概要

勇者が家で目覚めるところから始まり、村の老人に話を聞き、フィールドのモンスターと戦いながら魔王を倒すまでの小さな冒険を楽しめます。

### ゲームの流れ

```
タイトル画面
  └─ Z / Enter ─→ ゲーム開始
        │
        ├─ 家の中（スタート）
        │     └─ 扉から出る → 村へ
        │
        ├─ 村（アレフガルド村）
        │     ├─ 老人に話しかける（Zキー）
        │     └─ 村の端まで歩く → フィールドへ
        │
        ├─ フィールド
        │     ├─ 村アイコン（家）→ 乗ると村へ
        │     ├─ 城アイコン（塔）→ 乗ると魔王戦へ
        │     └─ エンカウントゾーン → はぐれメタル出現
        │
        ├─ 戦闘（コマンド式）
        │     ├─ たたかう / にげる
        │     ├─ はぐれメタル：HP低め・簡単
        │     └─ 大魔王ゾーマ：HP高め・やや強い
        │
        └─ エンディング → タイトルに戻る
```

### マップ構成

| マップ | サイズ | 内容 |
|--------|--------|------|
| 家の中 | 10×9 | スタート地点。扉から村へ |
| 村 | 20×15 | 老人NPC・家の扉 |
| フィールド | 20×15 | 村・城・エンカウントゾーン（画面ぴったり収まる） |

## 操作方法

| キー | 動作 |
|------|------|
| `W` / `↑` | 上に移動 |
| `S` / `↓` | 下に移動 |
| `A` / `←` | 左に移動 |
| `D` / `→` | 右に移動 |
| `Z` / `Enter` | 決定・話しかける |
| `Space` | 決定（代替） |

### 戦闘操作

| キー | 動作 |
|------|------|
| `↑` / `W` | コマンドカーソル上 |
| `↓` / `S` | コマンドカーソル下 |
| `Z` / `Enter` | コマンド決定 |
